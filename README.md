# Traffic Analysis Attacks against AI Systems at Scale

A reproducible experimental framework for collecting, analyzing, and fingerprinting network traffic generated by Large Language Models (LLMs) during streaming inference. This repository provides the data-collection infrastructure for studying whether LLMs can be identified solely from their network traffic patterns.

### 1-Model_downloader

Downloads HuggingFace models to a local flat directory for offline use by the Docker-based inference containers.

- **`downloader.py`** — Downloads a single model via `huggingface_hub.snapshot_download()`
- **`downloader.sh`** — Batch-downloads all target models

### 2-Data-collector

Baseline experiment: captures streaming traffic for **60 prompts** across 6 categories (text summarization, code generation, mathematical reasoning, adversarial/malware, logical puzzles, technical explanation). Each prompt is sent to a fresh inference container, and all eth0 traffic is captured via a tcpdump sidecar.

- Prompts are sourced from MMLU, LLMAP, and custom adversarial benchmarks
- Default model: `Qwen/Qwen2.5-7B-Instruct`
- Supports repeated-prompt mode (`-p N -r 100`) for statistical sampling

### 3-Temperature-change

Identical to 2-Data-collector but with a **configurable `TEMPERATURE` variable** at the top of `inference_server.py`. Enables measuring how sampling temperature (0.0–1.0+) affects inter-token timing, packet sizes, and stream duration.

- Default model: `MegaScience/Qwen3-14B-MegaScience`
- Current temperature: `0.9` (editable at `inference_server.py:30`)

### 4-Crafted-Prompts

Traffic capture using **adversarially crafted prompts** following the prompt-injection methodology described in the [LLMmap paper](https://www.usenix.org/conference/usenixsecurity25/presentation/pasquini). Each of the 10 prompts combines a legitimate reasoning question with injected suffixes:

- **GCG-style suffixes** (`))))]]]]}}}};*/` + "ignore previous instructions")
- **Appended meta-questions** (training dataset size, data cutoff date)
- **Language switching** (French/Spanish mid-prompt)
- **Identity/policy probing** ("who created you", "is 9/11 real?")

### 5-Scalability

Tests whether traffic fingerprints **generalize across models**. The same 10 code-generation prompts are sent to models spanning 3B–14B parameters across multiple architectures:

| Size | Models                                                                                        |
| ---- | --------------------------------------------------------------------------------------------- |
| ~3B  | LLaMA-3.2-3B-SRL, XtraGPT-3B, LaaLM-exp-v1, Yuuki-NxG                                         |
| ~4B  | Phi-4-mini-reasoning, glider, Sailor-4B, Qwen1.5-4B-Chat                                      |
| ~7B  | AceReason-Nemotron-1.1-7B, Qwen2.5-7B-Instruct, neural-chat-7b-v3-3, Mistral-7B-Instruct-v0.2 |
| ~8B  | typhoon2-8b-instruct, LLMTwin-Llama-3.1-8B, Tulu-3-8B, dolphin-2.9-llama3-8b                  |
| ~14B | Qwen3-14B-Base, Qwen3-14B-MegaScience, Qwen3-14B-Gemini-3-Pro-Distill, Qwen3-14B-Heretic      |

### 6-Delay

Evaluates fingerprint **robustness under network perturbation**. Uses Linux `tc netem` to inject artificial delay and jitter into the inference container's network namespace before capturing traffic.

- CLI flags: `--net-delay`, `--net-jitter`, `--net-distribution`
- Supported distributions: `normal`, `pareto`, `paretonormal`
- Default in `r1.py`: 500ms delay, 50ms jitter

## Prerequisites

- NVIDIA GPU with drivers + `nvidia-container-toolkit`
- Docker (with GPU passthrough)
- Python 3.10+ on the host
- `pip install huggingface_hub` (for model downloading)
- HuggingFace token for gated models (`HF_TOKEN` env var or `--token` flag)

## Quick Start

```bash
# 1. Download a model
python3 1-Model_downloader/downloader.py --model Qwen/Qwen2.5-7B-Instruct

# 2. Run the baseline experiment
cd 2-Data-collector
python3 main.py

# 3. Run a single prompt 100 times
python3 main.py --prompt 1 --repeat 100
```

## Output Format

Each experiment produces:

| Directory   | Contents                                                             |
| ----------- | -------------------------------------------------------------------- |
| `captures/` | PCAP files — full eth0 traffic per prompt (`.pcap`)                  |
| `logs/`     | Prompt text (`prompt_NN.txt`), model response + server logs (`.log`) |
| `models/`   | Pre-downloaded model weights (read-only bind mount)                  |

The client also emits a JSON line to stdout with per-token timing:

```json
{
  "index": 1,
  "response": "...",
  "timing": [
    { "t": 0.032, "dt": 0.0, "text": "The" },
    { "t": 0.089, "dt": 0.057, "text": " main" },
    { "t": 0.141, "dt": 0.052, "text": " points" }
  ]
}
```

## Configuration Reference

All experiments share these variables (set at the top of each `main.py`):

| Variable         | Description                            |
| ---------------- | -------------------------------------- |
| `MODEL`          | HuggingFace model ID                   |
| `DOCKER_NETWORK` | Isolated Docker bridge network name    |
| `GPU_DEVICE`     | GPU device for Docker (`device=0`)     |
| `MAX_TOKENS`     | Max tokens to generate (default: 2048) |
| `INFERENCE_PORT` | FastAPI server port (default: 8000)    |

Additional per-experiment variables:

| Experiment           | Variable             | Description                                            |
| -------------------- | -------------------- | ------------------------------------------------------ |
| 3-Temperature-change | `TEMPERATURE`        | Sampling temperature (top of `inference_server.py`)    |
| 6-Delay              | `--net-delay`        | Base delay in ms (CLI flag)                            |
| 6-Delay              | `--net-jitter`       | Jitter in ms (CLI flag)                                |
| 6-Delay              | `--net-distribution` | Jitter distribution (`normal`/`pareto`/`paretonormal`) |
